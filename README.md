 Heart Disease Prediction

 Overview
This project uses machine learning models to predict whether a patient has heart disease based on clinical features.

 Models Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Random Forest
- Support Vector Machine (SVM)

 Techniques
- Data preprocessing
- Exploratory Data Analysis (EDA)
- Cross-validation
- Hyperparameter tuning (GridSearchCV)

 Results
- Achieved ~86–88% accuracy
- Best models: Random Forest and KNN

 Tools
Python, pandas, NumPy, scikit-learn, matplotlib, seaborn
